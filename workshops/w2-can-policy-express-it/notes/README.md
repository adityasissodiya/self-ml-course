# Reading notes for Workshop 2

One file per reading, named by its ID from the workshop README (for example `R2.1.md`). Start each one from the template:

```text
python tasks.py note R2.1
```

A note counts as complete when no `TODO` remains. The dossier checks every core (`[LB]`) reading. Keep claims with their section or page numbers, and keep the reading's evidence tier in mind when the claim reaches a slide.

# 01 - The perceptron / linear unit

A perceptron is the smallest useful neural-network building block: a weighted
sum, a bias, and a decision rule. The same affine computation reappears inside
MLPs, attention projections, and the final language-model head.

## Learning objectives
After this module you can:
- Compute an affine score `w dot x + b` and interpret the bias term.
- Describe a linear decision boundary in two dimensions.
- Explain how a perceptron changes its weights after a mistake.
- Recognize why a single linear unit is useful but limited.

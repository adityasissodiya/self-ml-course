# 00 - Math & tooling prerequisites

This module sets the working vocabulary for the rest of the course. It is not
meant to be a gatekeeper; it is the minimum math and tooling you will use while
building the model.

## Learning objectives
After this module you can:
- Read vectors, matrices, shapes, and batched tensor notation without guessing.
- Use derivatives and the chain rule to reason about parameter updates.
- Explain why numerical stability matters for exponentials, logarithms, and
  floating-point code.
- Run the local course workflow: quizzes, numpy exercises, and project tests.

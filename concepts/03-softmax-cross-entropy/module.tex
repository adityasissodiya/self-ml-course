\section{Softmax, cross-entropy, and the output-layer gradient}\label{sec:03}
\conceptbadge{03}

A classifier's final linear layer produces a vector of real-valued scores
$z \in \mathbb{R}^{K}$ called \emph{logits}, one per class. Two things are
needed: turn the logits into a probability distribution, and measure how wrong
that distribution is against the true label. The softmax does the first;
cross-entropy does the second. This exact pair is the output layer and loss of a
next-token language model (milestone P9), where $K$ is the vocabulary size.

\subsection*{Softmax}
\[
  \mathrm{softmax}(z)_i \;=\; \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}.
\]
The outputs are positive and sum to one, so they form a distribution. Softmax is
invariant to an additive constant: for any scalar $c$,
\[
  \mathrm{softmax}(z+c)_i
    = \frac{e^{z_i+c}}{\sum_j e^{z_j+c}}
    = \frac{e^{c}\,e^{z_i}}{e^{c}\sum_j e^{z_j}}
    = \mathrm{softmax}(z)_i,
\]
because the $e^{c}$ cancels. This invariance is not just a surface property: it is what
allows the standard stability trick. Computing $e^{z_i}$ directly overflows for large
logits, so subtract the maximum $m=\max_j z_j$ first:
\[
  \mathrm{softmax}(z)_i \;=\; \frac{e^{z_i - m}}{\sum_{j} e^{z_j - m}}.
\]
Now the largest exponent is $e^{0}=1$; the remaining terms underflow harmlessly
toward zero.

\subsection*{Cross-entropy}
Let $p=\mathrm{softmax}(z)$ and let the target be a one-hot vector $y$ with a $1$
in the true-class position $t$. Cross-entropy is
\[
  L \;=\; -\sum_{i=1}^{K} y_i \log p_i \;=\; -\log p_t,
\]
the negative log-probability the model assigns to the correct class. Minimising
$L$ pushes $p_t \to 1$.

\subsection*{The gradient is $p-y$}
Write the loss directly in terms of the logits, using
$\log p_t = z_t - \log\sum_j e^{z_j}$:
\[
  L \;=\; -z_t + \log\sum_{j} e^{z_j}.
\]
Differentiate with respect to an arbitrary logit $z_i$. The first term
contributes $-1$ only when $i=t$; the second contributes
$e^{z_i}/\sum_j e^{z_j}=p_i$:
\[
  \frac{\partial L}{\partial z_i}
    \;=\; p_i - \mathbf{1}[i=t]
    \;=\; p_i - y_i,
  \qquad\text{i.e.}\qquad
  \nabla_z L = p - y.
\]
The gradient at the logits is simply \emph{prediction minus target}. This is the
single most reused gradient in the course: it collapses the output-layer
backward pass to a subtraction, and it reappears unchanged at the language-model
head in P9.

\subsection*{Stable log-sum-exp}
The same overflow concern applies to $\log\sum_j e^{z_j}$; compute it as
$m + \log\sum_j e^{z_j-m}$ with $m=\max_j z_j$. In practice, fuse softmax and
cross-entropy into one routine that takes logits and returns both $L$ and
$p-y$: this is faster and more stable than composing two separate ops, and it is
how you will implement it in the exercise and again in P2.

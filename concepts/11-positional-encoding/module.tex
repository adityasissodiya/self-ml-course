\section{Positional encoding}\label{sec:11}
\conceptbadge{11}

Self-attention compares token vectors, but the attention formula itself does
not know whether a token came first, last, or in the middle. Plain self-attention is
order-independent: if you reorder the input vectors and then reverse that
reordering on the outputs, you get the same result. In other words, attention by
itself does not know token order. Language is ordered, so a decoder needs
explicit position information.

\subsection*{Adding positions}
The common solution is simple:
\[
  H_{b,t,:} = E_{\text{token}}[x_{b,t}] + E_{\text{pos}}[t].
\]
The token embedding says what token is present. The position embedding says
where it appears. The sum has the same width as the model, so the rest of the
network can stay unchanged.

\subsection*{Learned positions}
Learned positional embeddings use a trainable table
$P \in \mathbb{R}^{T_{\max} \times C}$. Position $t$ gets row $P_t$. This is
straightforward and common in GPT-style models. The limitation is that the table
is defined only up to the configured context length unless you add special
handling for longer contexts.

\subsection*{Sinusoidal positions}
The original Transformer used fixed sinusoidal encodings:
\[
  PE_{t,2i} = \sin\left(t / 10000^{2i/C}\right),
  \qquad
  PE_{t,2i+1} = \cos\left(t / 10000^{2i/C}\right).
\]
Different dimensions oscillate at different frequencies. This gives each
position a structured signature and lets relative offsets be represented through
linear combinations of sinusoids.

\subsection*{What position encodings do not do}
Position encodings do not enforce causality; the mask does that. They also do
not replace token embeddings. They simply make order available to the model, so
attention and MLP layers can learn order-sensitive computations.

\subsection*{Exercise connection}
The exercise implements the sinusoidal formula. P7 may use learned or sinusoidal
positions depending on the project design, but both share the same interface:
produce a $T \times C$ table and add the first $T$ rows to token embeddings.
